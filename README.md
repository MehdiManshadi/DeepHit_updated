# DeepHit Updated

This repository is an updated version of the original DeepHit project.

## Purpose

- Preserve the DeepHit survival analysis implementation.
- Update dependencies and code to work with newer Python versions and modern libraries.

## Notes

- This is not the original DeepHit repository.
- It is a compatibility update for current Python environments.
- Use this repository when you need DeepHit-style modeling with updated packages.

## Usage

This repository contains the updated DeepHit survival analysis implementation.

Step-by-step explanation of the codebase:

1. `runDeepHit` is the main entry point for training and evaluating the model.
2. Supporting modules define the model architecture, loss functions, and data preprocessing.
3. Configuration files or scripts set dataset paths, hyperparameters, and training options.
4. Training runs through `runDeepHit`, which loads data, builds the model, and executes training loops.
5. Evaluation and prediction utilities are called after training to produce survival estimates.

To run the main code, execute `runDeepHit` with the appropriate dataset and configuration.
